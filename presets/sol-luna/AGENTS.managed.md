# Sol/Luna execution policy

The primary agent uses Sol at medium reasoning effort for analysis, architecture, planning, task decomposition, independent review, and final acceptance. Delegate bounded implementation, bug fixes, and focused testing to the `luna-worker`. Luna returns ambiguity, conflicting requirements, and scope changes to Sol for resolution. Use a Terra worker only when Luna is unavailable; do not substitute Terra merely for convenience.
